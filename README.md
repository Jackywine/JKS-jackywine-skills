# JKS jackywine skills

Jackywine 可共享的 skills 合集（JKS = Jackywine Skills）。

这里存放可复用、可开源的 agent skill：给 Grok Bot / Cursor 等助手直接加载，也可给其他人 fork 使用。

## 目录约定

每个 skill 一个子目录，内含 `SKILL.md`（以及需要时的辅助文件）。

```text
skills/
  <skill-id>/
    SKILL.md
```

## 使用方式

按你所用助手的 skill 安装方式，把对应目录拷入或引用即可。具体 skill 说明见各目录内的 `SKILL.md`。
